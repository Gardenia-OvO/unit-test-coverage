# 工具生态调研（组员 8 维护）

> 要求：调研主流编程语言（Java、Python、C++ 等）的单元测试与覆盖率工具生态。
> 目标篇幅 2000–3000 字，最后附一张三语言对比表。参考文献至少 6 条，优先官方文档。

## 一、Java

- 测试框架：JUnit 5（Platform / Jupiter / Vintage 三层结构）、TestNG
- 断言与替身：AssertJ、Hamcrest、Mockito
- 覆盖率：JaCoCo（字节码插桩；行 / 分支 / 指令 / 方法）
- 变异测试：PIT（用变异体存活率衡量断言有效性，本节可一句带过）
- 构建与 CI：Maven Surefire / Failsafe、GitHub Actions、SonarQube
- 我们为什么选它：加插件即可统计，不用改代码

## 二、Python

- 测试框架：pytest（fixture / parametrize / 插件体系）、unittest
- 覆盖率：coverage.py、pytest-cov
- 属性测试：hypothesis
- 变异测试：mutmut、cosmic-ray
- 特点：跑测试时顺带统计，侵入最小

## 三、C++

- 测试框架：GoogleTest、Catch2、doctest、Boost.Test
- 覆盖率：gcov / lcov、LLVM source-based coverage
- 变异测试：Mull
- 特点：统计覆盖率要重新编译，成本最高
