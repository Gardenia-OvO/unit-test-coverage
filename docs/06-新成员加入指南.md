# 新成员加入指南

> 给组员看。按顺序做完，你就能往仓库里交东西了。
> 全程大约 10 分钟，其中最费时间的可能不是注册，而是网络。

---

## 一、群公告（组长直接复制发群）

```
仓库地址：https://github.com/Gardenia-OvO/unit-test-coverage （公开的，不登录也能看）

需要你做的三件事：
1. 注册 GitHub 账号（没账号的）：https://github.com/signup
   注册完把【用户名】发群里，不要发密码。
2. 收到我发的邀请后，去邮箱点 Accept，或者在网页上点接受。
3. 在电脑上配一次身份 + 一次 Token，之后就能正常 push 了（见本文件第四、五节）。

打不开 github.com 的人：先别折腾，直接把东西打包发群里，我来代提。
```

---

## 二、注册账号

1. 打开 https://github.com/signup
2. **用户名**建议用「拼音 + 数字」，例如 `zhangsan2024`。仓库是公开的，**别用真实姓名全拼**，也别用学号。
3. **邮箱**用能正常收信的就行，QQ 邮箱也可以。
4. 可能会遇到人机验证，按提示点完。
5. 邮箱会收到验证码/验证链接，点掉才算注册成功。
6. 注册完，把你的**用户名**发到群里（不是密码，不是邮箱）。

> **打不开 github.com 怎么办**：说明当前网络连不上。换手机热点再试一次；还不行就先别注册，走「打包发群里」这条路，不影响你按时交东西。

## 三、组长加协作者

拿到用户名后，组长执行（把 `USERNAME` 换成对方用户名）：

```bash
gh api -X PUT repos/Gardenia-OvO/unit-test-coverage/collaborators/USERNAME -f permission=push
```

一次加多个人：

```bash
for u in user1 user2 user3 user4 user5 user6 user7; do
  gh api -X PUT repos/Gardenia-OvO/unit-test-coverage/collaborators/$u -f permission=push
done
```

查已经加进来的人：

```bash
gh api repos/Gardenia-OvO/unit-test-coverage/collaborators --jq '.[].login'
```

查还没接受邀请的人：

```bash
gh api repos/Gardenia-OvO/unit-test-coverage/invitations --jq '.[].invitee.login'
```

也可以直接在网页上点：仓库页 → Settings → Collaborators → Add people。

> **加完不算完，对方必须点「接受」**，不点的话推送会报 `Permission denied`。

## 四、配一次身份（所有人都要做）

在终端执行，只做一次：

```bash
git config --global user.name "组员5"
git config --global user.email "你注册 GitHub 用的邮箱"
```

`user.name` 会显示在提交记录里，写「组员5」比写真名更清楚，也避免真名公开。

## 五、能推代码：对号入座

### Windows 同学（大多数人）：什么都不用配

Git for Windows 自带 Git Credential Manager。**第一次 `git push` 会弹一个窗口**，选 **Sign in with your browser**，浏览器里点一下授权就完事了。

**不需要 Token，不需要密码。** 弹窗登录一次，之后就一直有效。

> 如果 Git Bash 里 push 完毫无反应、只在等密码，说明弹窗被挡了。看下面 macOS 那一节，手动配 Token。

### macOS 同学，或者弹窗登录失败：手动生成 Token

**GitHub 早就不允许用账号密码推代码了**，必须用 Token。

1. 登录 GitHub，右上角头像 → **Settings**
2. 左侧拉到最下面 → **Developer settings**
3. **Personal access tokens** → **Tokens (classic)** → **Generate new token (classic)**
4. Note 填 `course`；Expiration 选一个月；**勾选 `repo` 这一整块**（必须勾，否则推不上去）
5. 点 Generate，页面上会出现一串 `ghp_xxxxxxxx`，**只显示这一次，立刻复制到记事本**
6. 让电脑记住它（只需要做一次）：

```bash
git config --global credential.helper osxkeychain
```

7. 第一次 `git push` 时会问：
   * `Username`：填你的 **GitHub 用户名**
   * `Password`：**粘贴刚才那串 Token**（不是账号密码）

### 不想碰命令行：GitHub Desktop

1. 下载 https://desktop.github.com 装上（Windows / macOS 都有）
2. 打开 → **File → Clone repository** → 选 `Gardenia-OvO/unit-test-coverage`
3. 登录时选 **Sign in with browser**，浏览器点一下授权，不需要 Token
4. 之后改文件 → 左下角填一句说明 → **Commit** → **Push**

图形界面能看懂的话，这条路比命令行省事。

## 六、验证：确认你真的能交东西

按仓库根目录 README.md 第四节的流程走一遍（pull → add 自己的文件 → commit → push），
**能在网页上看到你改的内容，就算成功。**

看不到就对照下一节的报错表。

## 七、常见报错对照表

| 报错 | 原因 | 怎么办 |
|---|---|---|
| `Support for password authentication was removed` | 你填的是账号密码 | 换成 Token（第五节方式 A） |
| `Authentication failed` | 同上，或 Token 复制不全 | 重新生成 Token，勾选 `repo` |
| `remote: Permission to ... denied` | 还没被加协作者，或没点接受邀请 | 找组长加人 / 去邮箱点 Accept |
| `Permission denied (publickey)` | 用了 SSH 地址但没配密钥 | 改用 HTTPS 地址，或走方式 B |
| `SSL_ERROR_SYSCALL` / `Connection timed out` | 网络连不上 GitHub | 重试；换手机热点；改用 SSH 地址；都不行就打包发群 |
| `! [rejected] ... fetch first` | 别人刚推过东西 | 先 `git pull`，再 `git push` |
| `error: failed to push some refs` | 同上 | 同上 |
| 提交记录里名字显示成 `unknown` | 没配 user.name | 回到第四节 |
| `git: command not found` / `'git' 不是内部或外部命令` | Windows 没装 Git，或用了 PowerShell | 装 Git for Windows，用 Git Bash |
| `find` / `grep` 报参数错误 | 在 PowerShell 里敲了 bash 命令 | 换到 Git Bash |
| 文件列表里中文名字变成 `\344\276...` | 没设 quotepath | `git config --global core.quotepath false` |
